# Контекст проекта — Задача 1, v8

Модуль читает четыре источника Excel и выдаёт карточки клиентов, наблюдения документов, историю и отчёт качества без БД. Документы ТЗ в sources/ задают контекст; задачи 2–4 не реализуются этой поставкой.

В v8 выполнен полный пересчёт по таблицам из TZ.zip. Восстановлены в фактическом выходе 2 870 статусов F/G основной выгрузки и O базы I квартала. История теперь содержит 5 899 записей. Основные количества: 5 874 клиента, 87 933 допустимых и 3 877 отклонённых срезов, 3 683 замечания качества.

Исправление v7 сохранено: повтор с total=null использует только принятые опоры на другую дату того же клиента и периода. Значения total опор должны быть однозначны; исходный null сохраняется. Конфликты и иные отклонённые записи не являются опорами. Правило требует подтверждения предметной областью и не помечается как согласованное.

Карта 188 колонок обновлена по реальным заголовкам. Для неперенесённых в основные сущности колонок сохранены исходные непустые значения с координатами. Источники не исправлялись. Неоднозначный смысл не восстанавливался по догадке. Подробнее: README.md, contract.md, OPEN_QUESTIONS.md и результаты проверки.
