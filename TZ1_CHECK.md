# Сверка с ТЗ 1

Основание: «ТЗ 1 — Разбор Excel и единый формат.docx», редакция 26 октября 2026 года, и четыре Excel из TZ.zip. Эта сверка относится к текущим предоставленным файлам; она не подтверждает корректность для произвольной новой структуры источников.

| Требование | Проверенный результат |
| --- | --- |
| Работа без БД | Парсер и тесты запускаются локально без PostgreSQL и других модулей. |
| Четыре файла и все предусмотренные листы | Обработаны 4 файла, 7 листов. Карта содержит 188 колонок, заголовки сверены с Excel. |
| Разные строки заголовков | Основная база и квартальные файлы: строка 2; база должников: строка 1. |
| Широкие таблицы в отдельные наблюдения | 87 933 допустимых и 3 877 отклонённых срезов с отдельными периодами, датами и координатами. |
| Идентификаторы и происхождение | Координаты всех объектов и происхождение заполненных атрибутов сверены с исходными строками. |
| Исторические материалы | Все 5 899 записей истории сопоставлены исходным ячейкам, включая 5 150 исторических статусов. Проверены 20 471 поле истории. |
| Пропуски, дубли, неизвестные клиенты, ошибки чисел и дат | 3 683 замечания качества. Проблемные срезы изолированы с причинами. |
| Не исправлять неоднозначность молча | Спорные случаи сохранены в отчёте и OPEN_QUESTIONS.md; неперенесённые значения дополнительно сохранены с координатами. |
| Отсутствие total | Применено явно описанное техническое правило допуска; бизнес-правило остаётся открытым вопросом. 2 202 записи сохранены среди отклонённых. |
| Повторяемость | Повторный полный прогон и экспорт дают побайтно одинаковые шесть основных файлов. |
| Исходники не изменяются | Все 10 файлов sources/ сверены с оригиналами; контрольные суммы сохранены. |
| Тесты, инструкция и примеры | 19 тестов, README.md, contract.md, examples.json и независимая сверка verify_delivery.py. |

ТЗ не задаёт точной нормализованной схемы для всех исключённых колонок. Эти материалы сохранены как исходные значения без выдуманных событий; дальнейшая нормализация требует согласования. Наличие отчёта качества не означает, что исходные проблемы уже разрешены.
