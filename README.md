# Контур КЦР — Модуль разбора Excel и нормализации данных (Задача 1)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Code style: standard](https://img.shields.io/badge/code%20style-standard-brightgreen.svg)]()
[![Tests: unittest/pytest](https://img.shields.io/badge/tests-passed-success.svg)]()

Автономный ETL-модуль для разбора разнородных таблиц Excel, извлечения клиентов, преобразования широких срезов в плоские временные ряды, консолидации коммуникаций и проведения аудита качества данных.

---

## 📌 Архитектура и функционал

- **Независимость от СУБД**: модуль работает автономно без подключения к PostgreSQL и сторонним сервисам.
- **Унификация идентификаторов**: в качестве первичного ключа используется `source_client_id` (столбец A исходных файлов).
- **Разворачивание широких таблиц**: показатели за разные даты срезов (май, июль, сентябрь и т.д.) нормализуются в отдельные строки с фиксированными `period_start`, `period_end` и `as_of_date`.
- **Сохранение целостности `null`**: пустые ячейки строго сохраняются как `null` (`None`), предотвращая искажение нулями при последующих аналитических расчётах.
- **Трекинг происхождения (Provenance)**: каждая выходная запись содержит метаданные об источнике (`source_file`, `source_sheet`, `source_row`, `source_column`).
- **Сохранение контекста истории**: свободный текст комментариев операторов сохраняется целиком без искусственного деления дат.

## 🚀 Быстрый старт

### 1. Установка зависимостей

Для работы парсера требуется Python 3.10+ и библиотека `openpyxl`:

```bash
pip install -r requirements.txt
```

### 2. Запуск парсера

Поместите 4 исходных файла Excel в директорию со скриптом и выполните:

```bash
python parser_core.py
```

После выполнения в текущей директории обновятся все нормализованные артефакты и отчёты о качестве.

---

## 🧪 Запуск тестов

Тестовый набор покрывает проверку наличия выходных файлов, соблюдение контракта полей, формат дат `YYYY-MM-DD`, сохранение `null` и отлов аномалий качества.

**Запуск через стандартный модуль `unittest`:**
```bash
python -m unittest test_parser.py -v
```

**Запуск через `pytest`:**
```bash
pytest test_parser.py -v
```
