# Контур КЦР — Модуль разбора Excel и нормализации данных (Задача 1)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Code style: standard](https://img.shields.io/badge/code%20style-standard-brightgreen.svg)]()
[![Tests: unittest/pytest](https://img.shields.io/badge/tests-passed-success.svg)]()

Автономный ETL-модуль для разбора разнородных таблиц Excel, извлечения клиентов, преобразования широких срезов в плоские временные ряды, консолидации коммуникаций и проведения аудита качества данных.

---

## 📌 Ключевые возможности и архитектурные решения

- **Независимость от СУБД**: модуль работает автономно без подключения к PostgreSQL и сторонним сервисам.
- **Полное извлечение числовых показателей**:
  - Все 22 группы срезов из основной выгрузки (включая накопительные и полугодовые периоды).
  - Срезы по 4 периодам из оперативного файла от 20.10.2026.
  - Ретроспективные срезы на 6 дат наблюдения из базы должников 2025 года.
  - Срезы на 21.05.2026 из базы I кв 2026 года.
- **Двухпоточная маршрутизация срезов**:
  - `normalized_slices.jsonl`: валидные срезы, готовые к передаче в Задачу №2 и №3.
  - `rejected_slices.jsonl`: физически изолированные отклонённые срезы (неизвестные клиенты со статусом `blocked`, дубликаты в карантине, записи с числовыми дефектами).
- **Строгий парсинг чисел**: никаких молчаливых округлений дробных количеств или превращения битых строк (`#VALUE!`, `abc`) в null.
- **Структурированная история**: разделение первого касания и повторных звонков, сохранение статусов, дат перезвона и обязательств с точным указанием колонок.
- **Pre-flight проверки**: защита от запуска в пустой директории и проверка сигнатур колонок заголовков.

## 📂 Структура репозитория

```text
├── parser_core.py             # Основной скрипт парсинга, валидации и экспорта
├── test_parser.py             # Автономные автотесты (совместимы с unittest и pytest)
├── requirements.txt           # Зафиксированные версии внешних зависимостей
├── context.md                 # Описание бизнес-контекста и регламента задачи
├── README.md                  # Документация проекта для разработчиков
│
├── normalized_clients.json    # Реестр 5 874 уникальных клиентов
├── normalized_slices.jsonl    # Валидные нормализованные срезы документов
├── rejected_slices.jsonl      # Отклонённые срезы с причиной rejection_reason
├── normalized_history.jsonl   # 690 структурированных записей коммуникаций
├── quality_report.csv         # Аудит данных в табличном виде (для Excel)
└── quality_report.json        # Журнал аудита в машинночитаемом формате JSON
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск парсера

Поместите 4 исходных файла Excel в директорию со скриптом и выполните:

```bash
python parser_core.py
```

---

## 🧪 Запуск тестов

Тестовый набор генерирует фиктивные таблицы в памяти и проверяет строгость чисел, отлов битых строк, физическую изоляцию `blocked` и падение при отсутствии файлов:

```bash
python -m unittest test_parser.py -v
```
