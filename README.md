# Контур КЦР — Модуль разбора Excel и нормализации данных (Задача 1)

Автономный ETL-модуль для разбора четырёх таблиц Excel, извлечения базы клиентов, нормализации срезов документов, сохранения структурированной истории контактов и формирования отчёта качества данных.

---

## 📌 Ключевые характеристики актуальной сборки

- **5874 клиента** (`normalized_clients.json`)
- **87 933 допустимых среза** (`normalized_slices.jsonl`) — полностью очищены от неизвестных клиентов, дублей, неоднозначных дат и числовых ошибок.
- **3 877 отклонённых срезов** (`rejected_slices.jsonl`) — изолированные записи с явно указанной причиной `rejection_reason`.
- **749 записей истории** (`normalized_history.jsonl`) — включая 52 комментария для претензии (столбец `J`), первое касание (`AT-AX`), повторный звонок (`BA-BE`), инциденты и запросы эксперта (`BF-BH`), а также контакты I кв. 2026 (`AI-AM`) с маскированием телефоноподобных фрагментов.
- **3 683 замечания качества** (`quality_report.json` и `quality_report.csv`).
- **Транзакционный экспорт**: при записи выходного комплекта используется резервная копия `_backup` и промежуточная директория `_staging` с автоматическим откатом при сбое.
