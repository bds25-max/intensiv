# ТЗ №6 — веб-интерфейс

Текущая версия находится в [web](web/). React + TypeScript, мок-сервер и вымышленные данные. ТЗ №5 и №7 ещё не подключены.

## Запуск

Нужен Node.js 22+. Из корня репозитория:

```bash
cd web
npm ci
npm run dev
```

Логины: `admin`, `anna`, `ivan`. Пароль всех демонстрационных пользователей: `demo`.

Проверки: `npm test` и `npm run build`. Для браузерных сценариев: `npx playwright install chromium`, затем `npm run test:e2e`.

[Подробное описание](web/README.md) · [Подключение API](web/docs/INTEGRATION.md) · [Состояние приёмки](web/docs/ACCEPTANCE.md).

Реальная загрузка Excel и модель ИИ отсутствуют. Контракт OpenAPI предварительный и требует согласования с исполнителем ТЗ №5. Данные заказчика в интерфейс не включены.
